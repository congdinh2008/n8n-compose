## Daily Digest Automation

### Use Case

Tổng hợp thông tin quan trọng từ nhiều nguồn vào một email/message hàng ngày.

### Workflow

```
[Schedule: Daily 7AM]
       │
       ▼
[Fetch Today's Calendar Events]
       │
       ▼
[Fetch Unread Important Emails]
       │
       ▼
[Fetch Today's Tasks]
       │
       ▼
[Fetch News from RSS]
       │
       ▼
[Compile Digest]
       │
       ▼
[Send to Email/Telegram]
```

### Implementation

**Step 1: Schedule Trigger**

```json
{
  "name": "Schedule - Daily 7AM",
  "type": "n8n-nodes-base.scheduleTrigger",
  "parameters": {
    "rule": {
      "interval": [{ "field": "days", "triggerAtHour": 7 }]
    }
  }
}
```

**Step 2: Fetch Calendar**

```javascript
// Google Calendar: Get today's events
const calendar = await $('Google Calendar').execute('getAll', {
  calendarId: 'primary',
  timeMin: $now.startOf('day').toISOString(),
  timeMax: $now.endOf('day').toISOString()
});

return {
  json: {
    events: calendar.map(event => ({
      title: event.summary,
      time: event.start.dateTime,
      location: event.location
    }))
  }
};
```

**Step 3: Fetch Important Emails**

```javascript
// Gmail: Get unread important emails
const emails = await $('Gmail').execute('getAll', {
  q: 'is:unread is:important',
  maxResults: 10
});

return {
  json: {
    emails: emails.map(email => ({
      from: email.from,
      subject: email.subject,
      snippet: email.snippet,
      date: email.date
    }))
  }
};
```

**Step 4: Compile Digest**

```javascript
const calendar = $('Calendar').item.json.events;
const emails = $('Emails').item.json.emails;
const tasks = $('Tasks').item.json.tasks;
const news = $('RSS').item.json.articles;

const digest = `
# 📋 Daily Digest - ${$now.toFormat('dd/MM/yyyy')}

## 📅 Today's Schedule
${calendar.map(e => `- ${e.time}: ${e.title}`).join('\n')}

## 📧 Important Emails (${emails.length})
${emails.map(e => `- From: ${e.from}\n  Subject: ${e.subject}\n`).join('\n')}

## ✅ Tasks Due Today (${tasks.length})
${tasks.map(t => `- [ ] ${t.title}`).join('\n')}

## 📰 News Highlights
${news.slice(0, 5).map(n => `- [${n.title}](${n.url})`).join('\n')}

---
Generated by N8N at ${$now.toFormat('HH:mm')}
`;

return { json: { digest } };
```

**Step 5: Send via Email**

```json
{
  "name": "Send Digest Email",
  "type": "n8n-nodes-base.gmail",
  "parameters": {
    "operation": "send",
    "to": "={{ $env.MY_EMAIL }}",
    "subject": "📋 Daily Digest - {{ $now.toFormat('dd/MM/yyyy') }}",
    "emailType": "text",
    "message": "={{ $json.digest }}"
  }
}
```

## Task Management

### Use Case

Tự động tạo tasks từ emails, messages, và other sources.

### Workflow: Email to Task

```
[Gmail: New Email with ★]
       │
       ▼
[Extract Task Info]
       │
       ▼
[Create Task in Todoist/Notion]
       │
       ▼
[Send Confirmation]
```

**Implementation:**

```javascript
// Extract task from email
const email = $input.first().json;

// Simple NLP for due dates
const dueDatePatterns = {
  'tomorrow': $now.plus({ days: 1 }),
  'next week': $now.plus({ weeks: 1 }),
  'today': $now
};

let dueDate = $now.plus({ days: 3 }); // default

for (const [pattern, date] of Object.entries(dueDatePatterns)) {
  if (email.subject.toLowerCase().includes(pattern)) {
    dueDate = date;
    break;
  }
}

// Create task
const task = {
  content: email.subject,
  description: email.snippet,
  due_date: dueDate.toFormat('yyyy-MM-dd'),
  priority: email.starred ? 3 : 1,
  labels: ['email', email.from]
};

return { json: task };
```

```
       │
       ▼

       │
       ▼
[Send Evening Review]
```

## Email Management

### Use Case

Tự động phân loại, lọc, và xử lý emails.

### Workflow 1: Email Triage

```
[Gmail: New Email]
       │
       ▼
[Check if Newsletter] → [Archive]
       │
       ▼
[Check if from VIP] → [Label + Notify]
       │
       ▼
[Check has Action Items] → [Create Task]
       │
       ▼
[Default] → [Inbox]
```

**Classification Logic:**

```javascript
const email = $input.first().json;

// Newsletter patterns
const newsletterPatterns = ['unsubscribe', 'newsletter', 'digest'];
const isNewsletter = newsletterPatterns.some(pattern => 
  email.body.toLowerCase().includes(pattern)
);

// VIP contacts
const vipContacts = ['boss@company.com', 'important@client.com'];
const isVIP = vipContacts.includes(email.from);

// Action items
const actionPatterns = ['action required', 'please review', 'deadline'];
const hasAction = actionPatterns.some(pattern => 
  email.subject.toLowerCase().includes(pattern)
);

let action;
if (isNewsletter) action = 'archive';
else if (isVIP) action = 'notify';
else if (hasAction) action = 'create_task';
else action = 'inbox';

return { json: { ...email, action } };
```

### Workflow 2: Auto-respond to Common Questions

```
[Gmail: New Email]
       │
       ▼
[Check if FAQ]
       │
    ┌──┴──┐
    ▼     ▼
[Yes]  [No]
  │      │
  ▼      ▼
[Auto-reply] [Do nothing]
```

## Note-taking Automation

### Use Case

Tự động lưu highlights, clippings, và important information.

### Workflow: Save to Notion

```
[Telegram: Save Message]
       │
       ▼
[Parse Content]
       │
       ▼
[Add to Notion Database]
       │
       ▼
[Confirm Saved]
```

**Implementation:**

```javascript
const message = $input.first().json;

// Parse content
const content = message.text;

// Extract tags (words after #)
const tags = content.match(/#\w+/g) || [];

// Clean content
const cleanContent = content.replace(/#\w+/g, '').trim();

// Determine category
const categories = {
  'idea': /idea|thought|maybe/i,
  'task': /todo|task|need to/i,
  'quote': /quote|saying/i,
  'link': /http/i
};

let category = 'general';
for (const [cat, pattern] of Object.entries(categories)) {
  if (pattern.test(cleanContent)) {
    category = cat;
    break;
  }
}

// Prepare for Notion
const notionPage = {
  parent: { database_id: process.env.NOTION_DB_ID },
  properties: {
    Title: { title: [{ text: { content: cleanContent.slice(0, 50) } }] },
    Category: { select: { name: category } },
    Tags: { multi_select: tags.map(t => ({ name: t.slice(1) })) },
    Source: { select: { name: 'Telegram' } },
    Created: { date: { start: new Date().toISOString() } }
  },
  children: [
    {
      object: 'block',
      type: 'paragraph',
      paragraph: {
        rich_text: [{ type: 'text', text: { content: cleanContent } }]
      }
    }
  ]
};

return { json: notionPage };
```

## Habit Tracking

### Use Case

Theo dõi thói quen hàng ngày với reminders và reporting.

### Workflow: Daily Check-in

```
[Schedule: Daily 9PM]
       │
       ▼
[Get Today's Habits Status]
       │
       ▼
[Check Completion]
       │
       ▼
[Send Reminder if Missing]
```

**Implementation:**

```javascript
const habits = [
  { name: 'Exercise', completed: false },
  { name: 'Read 30min', completed: false },
  { name: 'Meditate', completed: false },
  { name: 'No sugar', completed: false }
];

// Check from tracker (Google Sheets, Notion, etc.)
const todayData = $('Tracker').item.json;

habits.forEach(habit => {
  habit.completed = todayData[habit.name.toLowerCase()] || false;
});

const incomplete = habits.filter(h => !h.completed);

const message = incomplete.length > 0 
  ? `⚠️ Missing habits today:\n${incomplete.map(h => `- ${h.name}`).join('\n')}`
  : '✅ All habits completed today! Great job!';

return { json: { message, incomplete } };
```

## Best Practices cho Personal Use

### 1. Start Small

Bắt đầu với 1-2 workflows đơn giản:
- Daily digest
- Email to task

Sau đó mở rộng dần.

### 2. Keep it Private

```bash
# Use .env file cho personal data
MY_EMAIL=me@gmail.com
NOTION_API_KEY=secret_xxx
TODOIST_TOKEN=xxx

# Never commit credentials
echo ".env" >> .gitignore
```

### 3. Use Free Tier

N8N self-hosted là miễn phí. Chỉ cần:
- 1 VPS ($5/tháng)
- Hoặc chạy local trên máy cá nhân

### 4. Backup Regularly

```bash
# Weekly backup script
0 2 * * 0 /backup/personal-n8n.sh
```

### 5. Monitor Usage

Theo dõi:
- Số executions/ngày
- API calls usage
- Storage used
