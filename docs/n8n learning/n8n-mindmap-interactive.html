3. Core Concepts — Khái niệm cốt lõi
Mixed ▼
3.1 Workflows Beginner
  • Định nghĩa: Chuỗi nodes kết nối thành automation pipeline
  • Lifecycle: Draft → Active → Deactivated → Archived
  • Structure: JSON với nodes[], connections{}, settings{}
  • Tags & Folders: Tổ chức workflow theo dự án/team
3.2 Nodes — 3 loại chính Beginner
  • Trigger nodes: Khởi động workflow — Schedule, Webhook, App events
  • Action nodes: Thực hiện task — HTTP, Database, Send Email, API calls
  • Logic nodes: Control flow — IF, Switch, Merge, Loop, Wait
💡 Tip: 500+ built-in nodes 2026 — luôn check trước khi viết custom code
3.3 Connections Beginner
  • Main connection: Data flow chính giữa nodes
  • Error connection: Branch riêng cho lỗi (output thứ 2)
  • AI connections: Tool, Memory, Model (cho LangChain nodes)
3.4 Data Structure Intermediate
  • Items array: Mỗi node nhận/trả về array of items
  • Item shape: { json: {...}, binary: {...}, pairedItem: {...} }
  • JSON: Data chính, dễ access qua expressions
  • Binary: Files, images — handle riêng để tối ưu memory
  • pairedItem: Trace data lineage qua các nodes
3.5 Credentials Intermediate
  • Types: API Key, OAuth2, Basic Auth, Custom credentials
  • Encryption: AES-256 với N8N_ENCRYPTION_KEY
  • Sharing: Per-user / shared / project-scoped (Enterprise)
  • External secrets: Vault, AWS Secrets Manager (Enterprise)
⚠️ Security: Không bao giờ commit .env có N8N_ENCRYPTION_KEY vào Git
3.6 Triggers — Cơ chế khởi động Intermediate
  • Schedule: Cron expression — định kỳ chạy
  • Webhook: HTTP endpoint — push từ ngoài vào
  • App Trigger (Push): Realtime — Gmail, Slack, Stripe events
  • App Trigger (Poll): n8n polling app theo interval
  • Manual: Click "Execute" — chỉ dùng testing
  • Form Trigger: n8n form built-in (no-code form)
3.7 Executions Intermediate
  • Modes: Manual / Trigger / Webhook / Retry
  • Status: Success / Error / Running / Canceled / Waiting
  • Retention: Cấu hình bao lâu giữ execution data
  • Save settings: "Save successful" / "Save errors only"

4. Expressions & Code Node
Tech ▼
4.1 Expression Syntax Intermediate
  • Cú pháp: {{ expression }} — JavaScript template literals
  • Current item: {{ $json.field }}
  • First/all items: {{ $input.first().json.x }}, {{ $input.all() }}
  • Other nodes: {{ $('Node Name').item.json.x }}
  • Variables: $now, $today, $workflow, $execution, $env
4.2 Built-in Helpers Intermediate
  • Date/Time: Luxon DateTime — $now.plus({days: 7})
  • String: .toUpperCase(), .replaceAll(), .split()
  • Array: .map(), .filter(), .reduce(), .sort()
  • JMESPath: $jmespath($json, "items[?status=='active']")
  • Crypto: $crypto.hash(), $crypto.uuid()
4.3 Code Node — JavaScript Advanced
  • 2 modes: "Run Once for All Items" / "Run Once for Each Item"
  • Return: Array of { json: {...} } objects
  • Built-in libs: crypto, axios, moment, lodash (limited sandbox)
  • External modules: Cần config NODE_FUNCTION_ALLOW_EXTERNAL
💡 Pattern: Dùng Code node khi expression quá phức tạp — dễ test & maintain hơn
4.4 Code Node — Python Advanced
  • Pyodide runtime — chạy Python trong browser/Node sandbox
  • Hạn chế: Slower than JS, không phải tất cả lib có sẵn
  • Phù hợp: Data science, scientific computing, sẵn code Python
4.5 HTTP Request node (deep dive) Advanced
  • Auth: None, Basic, Header, OAuth2, Bearer, Custom
  • Pagination: Built-in handlers — offset, page, link header, next URL
  • Retry: Configurable retries với exponential backoff
  • Streaming: Hỗ trợ binary data, SSE

5. Workflow Patterns & Error Handling
Tech ▼
5.1 Workflow Design Patterns Intermediate
  • Sequential: A → B → C tuần tự
  • Conditional (IF/Switch): Branch theo điều kiện
  • Parallel/Fan-out: Split → multi-branch chạy song song
  • Fan-in/Merge: Hợp nhất kết quả từ nhiều nhánh
  • Loop Over Items: Xử lý batch theo size
  • Wait & Delay: Async pause, resume sau N giây/event
  • Circuit Breaker: Tự ngắt khi service downstream lỗi liên tục
5.2 Sub-workflows (Reusability) Advanced
  • Execute Workflow node: Gọi workflow khác như function
  • Input/Output mapping: Pass data qua tham số
  • Use case: Shared logic, microservice pattern, version control
💡 Best practice: Tách logic dùng chung (auth, logging, notification) thành sub-workflow để DRY
5.3 Error Handling Strategies Intermediate
  • Error Trigger: Workflow riêng catch lỗi từ workflow khác
  • Continue On Fail: Setting trên node — không break flow
  • Try/Catch pattern: Dùng IF check output error
  • Stop and Error node: Throw custom error
5.4 Retry Logic Advanced
  • Node-level retry: Retry On Fail — set max attempts, wait time
  • Exponential backoff: Wait 2^n giây mỗi lần retry
  • Idempotency: Đảm bảo retry không gây side effect kép
  • Dead letter queue: Lưu request fail vào queue riêng để xử lý sau
5.5 Debugging Techniques Intermediate
  • Pin data: Lock output để dev nhanh, không gọi API lại
  • Execute previous nodes: Re-run từ node bất kỳ
  • Step-by-step execution: Test từng node độc lập
  • Console.log trong Code node: Xem output ở execution log

7. Production & Scaling
Tech ▼
7.1 Queue Mode — Khi nào? Advanced
  • <1,000 exec/ngày: Standard mode + PostgreSQL — đủ dùng
  • 1,000–10,000: Queue mode + 1 worker
  • >10,000: Queue mode + multi workers + webhook processors
  • Trigger: Webhook latency >1s hoặc >10-20 concurrent execs
7.2 Queue Mode Architecture Advanced
  • Main process: UI, push jobs vào Redis queue
  • Workers: Pull jobs từ Redis, execute, update status
  • Webhook processors: Tách riêng cho high-volume webhooks
  • Redis: Message broker bắt buộc
  • PostgreSQL: Required — SQLite không support queue mode
7.3 Critical Configuration Advanced
  • EXECUTIONS_MODE=queue — bật queue mode (main + workers)
  • N8N_ENCRYPTION_KEY — phải giống nhau trên main + tất cả workers
  • QUEUE_BULL_REDIS_HOST/PORT/PASSWORD — connection Redis
  • N8N_CONCURRENCY_PRODUCTION_LIMIT — số job parallel/worker
⚠️ Pitfall: Encryption key khác nhau giữa workers → workflow chạy nhưng API call fail vì không decrypt được credentials
7.4 Resource Planning Advanced
  • Worker memory: 200-500MB/worker (cao hơn nếu data transform nặng)
  • Node.js heap: NODE_OPTIONS=--max-old-space-size=4096
  • Binary data: Mode filesystem hoặc S3 cho file lớn
  • DB sizing: Plan cho execution data retention
7.5 Monitoring & Observability Advanced
  • Prometheus metrics: N8N_METRICS=true — endpoint /metrics
  • Key metrics: Queue length, worker concurrency, exec duration, error rate
  • Health checks: /healthz, /healthz/readiness
  • Logging: Centralize (Loki, ELK) với workflow_id, execution_id
  • Alerting: Grafana + alert rules cho queue backlog, failed execs
7.6 Backup & DR Advanced
  • Database: pg_dump daily + WAL archive
  • Workflow export: CLI n8n export:workflow → Git
  • Credentials: Backed up encrypted in DB — cần ENCRYPTION_KEY để restore
  • Binary data: S3 versioning hoặc snapshot filesystem
7.7 Kubernetes Deployment Advanced
  • HPA: Auto-scale workers theo Redis queue depth
  • Pod separation: main / worker / webhook deployments riêng
  • Storage: PVC cho binary data, RDS/Cloud SQL cho DB
  • Network policy: Restrict ingress/egress, isolate workers

10. Best Practices
Mixed ▼
10.1 Naming & Organization Beginner
  • Workflow naming: [Team]-[Purpose]-[Trigger] — vd: Sales-LeadCapture-Webhook
  • Node naming: Action-based — "Fetch active leads" thay vì "HTTP1"
  • Tags: Theo domain (sales, hr, finance) + env (prod, dev)
  • Sticky notes: Document logic phức tạp ngay trên canvas
10.2 Security Intermediate
  • Credentials: Least privilege — API key chỉ cấp scope cần thiết
  • Encryption key: 32+ chars, lưu trong secret manager, không commit
  • HTTPS only: Force SSL, dùng Let's Encrypt / Cloudflare
  • Webhook auth: Header token / HMAC signature verify
  • RBAC: User roles, project-scoped credentials (Enterprise)
  • Audit log: Track ai sửa workflow gì khi nào
  • Rotation: Rotate credentials định kỳ (90 ngày)
10.3 Performance Intermediate
  • Batch processing: Tránh load 10k items 1 lần — split thành batches 100
  • Binary mode filesystem: Không giữ file lớn trong RAM
  • Pagination: Luôn dùng built-in pagination cho HTTP node
  • Cache: Cache API response không đổi (Redis, static node)
  • Rate limiting: Respect API limit — Wait node hoặc Code logic
  • Concurrency control: Giới hạn parallel để không quá tải downstream
10.4 Reliability Intermediate
  • Idempotency: Workflow chạy 2 lần cùng input → kết quả giống nhau
  • Error workflow: Tách workflow chuyên catch + alert + retry
  • Timeout: Set timeout cho mọi HTTP call (default vô hạn rất nguy hiểm)
  • Circuit breaker: Detect downstream lỗi → tạm dừng workflow
  • Monitoring: Alert qua Slack/Telegram khi workflow fail
10.5 Testing & QA Advanced
  • Test data: Pin sample data, không gọi production API khi dev
  • Staging env: Separate n8n instance cho test trước deploy
  • Manual triggers: Tạo workflow test riêng để verify subflow
  • Schema validation: Validate input/output bằng JSON Schema
  • Eval suite (AI): Test prompts với batch input, đánh giá quality
10.6 Version Control & CI/CD Advanced
  • n8n CLI export: n8n export:workflow --all → commit JSON vào Git
  • Source Control feature (Enterprise): Sync workflows với Git native
  • CI pipeline: Lint workflow JSON, deploy staging → test → prod
  • Workflow versioning: Tag releases, có rollback path
10.7 Documentation Beginner
  • Sticky notes: Why? + Edge cases + Owner
  • Workflow description: Trigger, owner, dependencies, runbook link
  • External docs: Notion/Confluence link cho business logic phức tạp

12. Troubleshooting
Tech ▼
12.1 Installation Issues Beginner
  • Permission denied (Docker): Set N8N_USER đúng UID/GID
  • Port conflict: 5678 đang dùng — đổi N8N_PORT
  • DB connection refused: Check network giữa containers
  • SQLite lock: Lập tức chuyển sang PostgreSQL
12.2 Workflow Execution Errors Intermediate
  • "Cannot read property of undefined": Item structure khác expected — check $json
  • Timeout: Tăng EXECUTIONS_TIMEOUT, set node-level timeout
  • Out of memory: Tăng heap, batch processing, binary filesystem mode
  • Rate limit (429): Wait node + retry với backoff
12.3 Webhook Issues Intermediate
  • Webhook không trigger: Check WEBHOOK_URL + workflow active
  • "Webhook not registered": Activate workflow + đợi 1-2s
  • HTTPS cert error: Verify SSL chain với openssl s_client
  • Body parsing: Check Content-Type — JSON vs form-data
12.4 Queue Mode Issues Advanced
  • Jobs stuck in queue: Check worker logs, Redis connection
  • Credential decryption fail: ENCRYPTION_KEY mismatch giữa main/worker
  • Webhook chậm: Add webhook processors riêng
  • Memory leak worker: Set MAX_PAYLOAD_SIZE, restart định kỳ
12.5 Debugging Workflow Intermediate
  • Execution logs: Editor → Executions → click vào execution → xem chi tiết
  • Pin data: Lock output node để re-run nhanh
  • Console.log: Dùng trong Code node, xem ở log container
  • Test webhook: curl -X POST với production URL
