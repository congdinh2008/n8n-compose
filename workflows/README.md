## 🚀 Quick Start

### 1. Import Workflow
```bash
1. Mở n8n Dashboard
2. Add Workflow → Import from File
3. Chọn file workflow.json
4. Click Import
```

### 2. Configure Credentials
- Google Sheets OAuth2
- Gmail OAuth2
- Slack OAuth2
- Telegram Bot Token

### 3. Test & Activate
```bash
1. Click Test Workflow
2. Gửi data mẫu (xem GUIDE.md)
3. Kiểm tra kết quả
4. Activate workflow
```

## ⚠️ Community Version Notes

### ✅ Available
- All core nodes (Code, HTTP Request, IF, Switch, Merge)
- 300+ app integrations
- Webhook & Schedule triggers
- Wait nodes
- Error handling
- Self-hosted (unlimited executions)

### ⚠️ Limitations
- OAuth2 credentials need periodic reconnection
- No queue mode (limited concurrent executions)
- No role-based access control
- SQLite default (use PostgreSQL for production)

### 🔧 Vietnamese Services
Use **HTTP Request** node for:
- **Shipping:** Giao Hàng Nhanh, Viettel Post
- **Payment:** MoMo, VNPay, ZaloPay
- **SMS:** Esms.vn, Vietguys
